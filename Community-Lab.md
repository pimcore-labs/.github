# Community Lab 

 - Pimcore Voyager - a mobile native App for Pimcore Studio (2026.x and upwards): https://github.com/dpfaffenbauer/PimcoreVoyager
 - Torq Expression Tester - a symfony expression tester bundle for Pimcore Studio:
    - GitHub: https://github.com/TorqIT/expression-tester-bundle
    - Packagist: https://packagist.org/packages/torq/pimcore-expression-tester-bundle
 - Factory Assets Viewer Bundle - A Pimcore bundle that enables preview functionality for 3D and CAD asset files directly within the Pimcore admin interface.
    - GitHub: https://github.com/factoryhr/factory-assets-viewer-bundle
 - CORS CDN Bundle - CDN providers for Pimcore's built-in CDN integration (2026.2 and upwards): Cloudflare, Google Cloud CDN, AWS CloudFront and Azure Front Door, with tag and URL purges, Cloudflare image transformations and support for stacked CDN layers.
      - GitHub: https://github.com/cors-gmbh/pimcore-cdn
      - Packagist: https://packagist.org/packages/cors/pimcore-cdn
